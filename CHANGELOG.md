# Журнал изменений

## 0.2.0-windows (этап: Windows-клиент)

Добавлено:
- Настольный клиент для Windows 10/11: .NET 8 + WPF, `windows/` в репозитории.
- WireGuard через официальный embeddable `tunnel.dll` (wireguard-windows, MIT);
  interop-слой — vendor-копия официального C#-примера (`windows/src/BlockVPN.Core/Interop/`).
- Машина состояний (Отключено/Подключение/Защищено/Переподключение/Ошибка) на трёх
  реальных источниках: служба, адаптер, свежесть хендшейка (<180 c).
- Автопереподключение: до 5 попыток с пересозданием службы.
- Профили: DPAPI-шифрование (`%APPDATA%\BlockVPN\profiles.bin`).
- «Мой тег», 3 палитры, стикеры, декор/анимации отключаемые.
- Диагностика: DNS, адаптер, служба, журнал туннеля (ringlogger).
- Unit-тесты парсера конфигов и форматирования (xUnit).
- CI `windows-build`: tunnel.dll собирается из официальных исходников wireguard-windows,
  wireguard.dll скачивается с download.wireguard.com с проверкой SHA256.

Проверено (CI): сборка и тесты — см. прогон workflow `windows-build`.
НЕ проверено на реальной машине с реальным сервером: установка, UAC, подключение,
kill switch, автозапуск — см. windows/README.md и docs/TESTING.md.

## 0.1.1 — доработки MVP (текущая)

### Добавлено
- Индикатор «Рукопожатие» в панели статистики: реальное время с последнего
  WireGuard-handshake (данные backend), скрывается при отсутствии.
- Юнит-тесты: `FormatTest` (8), `DiagnosticsTest` (6); зависимости JUnit 4.13.2,
  kotlinx-coroutines-test 1.7.3.
- CI-workflow `.github/workflows/ci.yml`: JDK 17 + Android SDK, assembleDebug,
  testDebugUnitTest, выгрузка APK-артефакта.

### Изменено
- Библиотека `com.wireguard.android:tunnel` обновлена с 1.0.20211029 до
  **1.0.20231018**: в старой версии Statistics не содержит данных о рукопожатии;
  новая совместима (compileSdk 34, minSdk 21, Java 17). API сверены с исходниками
  релиза (`setState(Tunnel, State, Config?)`, `Statistics.peers()/peer(Key)/PeerStats`).
- Форматирование трафика/времени вынесено в `util/Format.kt` (тестируемо без Android).

## 0.1.0 — MVP

### Добавлено
- WireGuard-подключение через официальную библиотеку `com.wireguard.android:tunnel`
  (GoBackend, userspace, без root).
- Автомат состояний: Отключено / Подключение / Защищено / Переподключение / Ошибка.
- Автоповтор подключения (до 5 попыток) и монитор туннеля (возврат после обрыва).
- Профили серверов: импорт/валидация/удаление, шифрование AES-256-GCM (AndroidKeyStore).
- Статистика: время сессии, принято/передано (обновление 1 раз/сек).
- UI в уличном стиле: статус-круг с неоновой подсветкой, тёмные темы
  («Ночной квартал», «Неон-молл», «Ржавый вагон»).
- «Мой тег»: надпись до 12 символов, 6 цветов, 3 стиля, подсветка при защите.
- 5 локальных стикеров-достижений; отключение анимаций и декора.
- Экран помощи: FAQ + диагностика VPN/DNS.
- Иконка-маскот (капюшон, наушники, визор) — adaptive icon.
- Документация: архитектура, сборка, настройка сервера, секреты, модель угроз,
  тесты, ограничения.

### Проверено
- CI (GitHub Actions, run 43769962041): `assembleDebug` — BUILD SUCCESSFUL,
  `testDebugUnitTest` — BUILD SUCCESSFUL (14 тестов), APK-артефакт выгружен.
- В процессе отладки CI исправлены: устаревший шаг setup-android, отсутствие
  `tunnel 1.0.20231018` на Maven Central (заменена на 1.0.20230706), фон adaptive-иконки,
  генерация BuildConfig в AGP 8.

### Известные проблемы
- См. `docs/LIMITATIONS.md` (не проверено на реальном устройстве: запуск, VPN-подключение,
  kill switch, переподключение).
