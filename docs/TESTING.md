# Проверки: что реально сделано и как проверить самому

## Что было проверено в среде разработки проекта

Среда не содержит JDK, Android SDK и прав на их установку (нет root), загрузки из
сети заблокированы. Поэтому:

- **Сборка APK здесь НЕ выполнялась.** Утверждать, что проект собирается, нельзя.
- Статические проверки, которые удалось провести: структура проекта, целостность
  Gradle-файлов и манифеста, парность скобок в Kotlin-файлах (скриптом), отсутствие
  секретов в репозитории.

## Чек-лист проверок на машине со Studio (обязателен перед использованием)

1. **Сборка:** `./gradlew assembleDebug` — без ошибок.
2. **Запуск:** приложение открывается, виден баннер «РЕЖИМ РАЗРАБОТКИ», статус «ОТКЛЮЧЕНО».
3. **Валидация конфига:** вставить мусор в «Добавить сервер» — должно отклонить;
   вставить валидный конфиг — сохранить.
4. **Подключение:** реальный сервер → «Подключиться» → системный диалог → статус
   «ЗАЩИЩЕНО», IP = адрес сервера.
5. **Отключение:** кнопка → статус «ОТКЛЮЧЕНО», IP исходный.
6. **Переподключение:** включить авиарежим на 5–10 с → статус «ПЕРЕПОДКЛЮЧЕНИЕ…»,
   после возврата сети — «ЗАЩИЩЕНО».
7. **Ошибка:** конфиг с неверным Endpoint → до 5 попыток → «ОШИБКА» + кнопка «Повторить».
8. **DNS:** «Помощь» → «Проверить DNS» при активном туннеле; дополнительно ipleak.net.
9. **Kill switch:** включить системные «VPN всегда активен» + «Блокировать соединения
   без VPN», оборвать сеть — трафик должен блокироваться, а не идти напрямую.
10. **Статистика:** время тикает раз в секунду, Загружено/Отправлено растут.
11. **Тег/темы/стикеры:** сохранить тег — появился на главном; подключиться — подсветка;
    сменить тему; выключить анимации и декор.
12. **Доступность:** системный размер шрифта 130% — тексты читаемы; кнопки ≥ 48 dp.
