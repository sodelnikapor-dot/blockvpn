# Секреты и переменные окружения

Ничего секретного в репозитории нет и не должно появиться.

## Приложение (сейчас)

| Секрет | Где хранится | Зачем |
|---|---|---|
| Приватные ключи WireGuard клиентов | Зашифрованный файл `profiles.enc` (AES-256-GCM, ключ в AndroidKeyStore) | Подключение к серверам |
| Мастер-ключ Keystore | Системный AndroidKeyStore, наружу недоступен | Шифрование профилей |

## Сборка release

| Переменная | Зачем |
|---|---|
| `BLOCKVPN_KEYSTORE_PATH` | Путь к release-keystore (файл вне репозитория) |
| `BLOCKVPN_KEYSTORE_PASSWORD` | Пароль keystore |
| `BLOCKVPN_KEY_ALIAS` | Алиас ключа |
| `BLOCKVPN_KEY_PASSWORD` | Пароль ключа |

## Серверная часть (этап 2+, когда будет подтверждение)

| Секрет | Зачем |
|---|---|
| Приватный ключ WireGuard сервера | `/etc/wireguard/wg0.conf`, права 600 |
| Токен подписи обновлений (Ed25519) | Подпись метаданных обновлений; публичный ключ зашит в приложении |
| TLS-сертификат домена | Let's Encrypt, автообновление |
| Токены устройств (БД API) | Выдача конфигураций только авторизованным клиентам |

## Правила

- Keystore и приватные ключи не коммитятся (см. `.gitignore`).
- Пароли — только через переменные окружения или менеджер секретов.
- Утечка release-ключа = возможность подделать обновления: хранить в резерве офлайн.
