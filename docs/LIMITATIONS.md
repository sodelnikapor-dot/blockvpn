# Известные ограничения и проблемы

1. **Сборка проверена в CI, но не на устройстве**: `assembleDebug` и
   `testDebugUnitTest` прошли успешно (GitHub Actions, run 43769962041).
   Не проверено: запуск на реальном телефоне, реальное VPN-подключение, kill switch,
   переподключение — см. чек-лист в `TESTING.md`.
2. **Серверной части нет**: список серверов ведётся вручную (импорт конфига).
3. **GoBackend (userspace)**: скорость ниже, чем у kernel-WG; на слабых устройствах
   возможны просадки при больших объёмах трафика.
4. **Kill switch** включается вручную в системных настройках Android; приложение не
   может включить его само (ограничение платформы).
5. **Переподключение** реализовано опросом состояния раз в 3 с — кратковременный
   разрыв может отображаться с задержкой до ~6 с.
6. **Опрос статистики и рукопожатия** работает только когда приложение открыто
   (экран «Главная»); фоновых сервисов статистики нет. Если handshake не обновлялся
   дольше 10 минут, индикатор скрывается (защита от устаревших данных).
7. **Автоподключение** срабатывает при открытии приложения, а не при загрузке ОС
   (для «при загрузке» нуженforeground-сервис/Boot-receiver — этап 2).
8. **Только русский язык** интерфейса.
9. **Обновления** — пока только через переустановку APK/стор; подписанный канал
   обновлений запланирован на этап 4.
10. **Эмодзи-стикеры** зависят от системного шрифта устройства.
11. **Таймер сессии** сбрасывается при перезапуске процесса приложения (счётчик
    «всего минут» сохраняется).
12. **VpnService и API 34**: если на некоторых прошивках появится ошибка
    foreground-service type, нужно добавить `android:foregroundServiceType="specialUse"`
    для сервиса `GoBackend$VpnService`.

## Windows-клиент (0.2.0-windows)

13. Права администратора обязательны (UAC при каждом запуске) — ограничение Windows для системных туннелей; так же работает официальный WireGuard.
14. Kill switch не автоматизирован: в Windows нет системного «блокировать всё без VPN»; подсказка по брандмауэру — во вкладке «Настройки».
15. Туннель эфемерный: закрывается вместе с приложением. Автозапуск через HKCU Run вызывает окно UAC при старте системы.
16. tunnel.dll и wireguard.dll не подписаны нашим сертификатом — SmartScreen может предупреждать при первом запуске; подпись кода планируется после выпуска.
17. Сборка и unit-тесты проверены в CI (windows-latest); установка и реальное VPN-подключение на живом сервере пока не проверялись.
