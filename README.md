# BLOCKVPN — VPN-клиент в уличном стиле (Android MVP)

WireGuard-клиент для Android с тёмным «уличным» интерфейсом, фирменной функцией
«Мой тег», локальными стикерами и темами. Ядро — официальная библиотека
[`wireguard-android`](https://www.wireguard.com/android/) (`com.wireguard.android:tunnel`),
никакой собственной криптографии.

## Что реально реализовано

- Подключение/отключение одной кнопкой через WireGuard (userspace backend, GoBackend).
- Профили серверов: импорт конфига `.conf` вручную, название и регион, выбор активного.
- Состояния: Отключено → Подключение → Защищено → Переподключение → Ошибка.
- Автоповтор подключения (до 5 попыток с нарастающей паузой) и монитор-цикл,
  который возвращает туннель при кратковременном обрыве.
- Время соединения, принято/передано (из статистики WireGuard).
- Импорт конфига с валидацией; приватные ключи шифруются AES-GCM ключом из Android Keystore.
- «Мой тег»: надпись, цвет, стиль; подсветка при защищённом соединении.
- 3 локальные темы, 5 локальных стикеров-достижений, отключение анимаций и декора.
- Экран помощи: FAQ + диагностика (активный VPN-интерфейс, разрешение DNS из конфига).
- Хук на системный kill switch: инструкция и кнопка открытия системных настроек VPN.
- Индикатор «Рукопожатие» (время с последнего WireGuard-handshake).
- Юнит-тесты (форматирование, разбор конфигов) и CI-workflow (сборка + тесты).
- Версия библиотеки WireGuard `tunnel` 1.0.20231018, API сверены с исходниками релиза.

## Чего здесь НЕТ (честно)

- Списка серверов из API, учётных записей, оплаты — серверной части пока нет.
- Гарантий постоянной работы: VPN может не подключиться (сервер недоступен, блокировки сети).
- Проверки на реальном устройстве: сборка и юнит-тесты (14 шт.) прошли в CI
  (GitHub Actions, APK-артефакт готов), но запуск на телефоне и реальное
  VPN-подключение ещё не проверены — чек-лист в `docs/TESTING.md`.

## Быстрый старт

1. Установи Android Studio (Hedgehog+) или Gradle 8.2 + JDK 17.
2. Открой папку проекта, дождись синхронизации Gradle.
3. `Run` на устройстве/эмуляторе с Android 8.0+ (реальный телефон нужен для настоящего VPN).
4. Без сервера приложение покажет баннер «РЕЖИМ РАЗРАБОТКИ» — это честное состояние,
   а не имитация подключения. Настрой свой сервер по `docs/SERVER_SETUP.md`.
